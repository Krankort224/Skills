# Design system

## Resolve precedence
Use explicit constraints first, then the selected template/layout, supplied brand, chosen preset and component defaults. Preserve a chosen template's visual identity. Never apply a neutral preset merely because it is available.

## Four concrete systems
Read the corresponding JSON in `../assets/presets/`; use its values directly. Values are design defaults, not GOST, institutional or publication compliance claims.

Each file owns page geometry, fonts and fallbacks, title/subtitle, H1–H6, body, caption, metadata, code, table and note roles; spacing; palette; list geometry; cell padding and footer. Do not duplicate these numbers in code. Copy and override a configuration for one task.

The previews show the same two-page content generated by `scripts/generate_examples.py`, including Cyrillic, nested numbering, tables, chart, native equation, code and page fields. They are examples of composition, not font-equivalence proofs. Their renderer used Nimbus Sans for Arial, DejaVu Sans for Calibri, Nimbus Roman for Times New Roman and DejaVu Sans Mono for Consolas; the preset files retain the requested font families.

## Type and roles
Use real Title, Subtitle, Heading 1–6, Normal, Caption and named Code/Metadata/Table Text/Note styles. Use heading depth to describe the outline; do not skip levels just to obtain a smaller font. H4–H6 remain distinct through weight and spacing even if their point sizes converge. Use a character style or explicit span for meaningful emphasis, not a separate paragraph style per sentence.

Keep normal paragraphs left aligned unless the source convention requires otherwise. Avoid full justification in narrow columns. Use sentence case for headings unless a selected template differs. Set widow control, heading keep-with-next and caption pairing deliberately. Do not chain every paragraph with keep-with-next.

## Font resolution
Check requested fonts with the environment's font inventory or Word. Calibri → Carlito; Arial → Liberation Sans; Times New Roman → Liberation Serif; Consolas → Liberation Mono are layout-oriented substitutions, not guaranteed identical metrics. Test Cyrillic, O₂, m³, arrows, Greek letters and formula glyphs. Report material substitution outside the document. Do not overwrite a selected template merely to suit the renderer; try available compatible fonts first.

## Color and printing
Use palette roles rather than arbitrary RGB in each component: ink, muted, accent, table_header, table_header_text, alternating_row, border, note_background. Choose dark text on light fills or white text on sufficiently dark fills. Evaluate both color and grayscale; labels must carry meaning without color. Brand names/logos require user/source authority; a neutral preset accent does not imply a fabricated brand.

## Direct formatting and themes
Named styles form the baseline; direct run formatting can legitimately carry emphasis or template-specific treatment. Inspect overrides before restyling. Remove only overrides known to contradict the requested change. Avoid global clearing of run properties: it can erase emphasis, hyperlinks, symbols and special fonts.

## Page roles
Choose a compact first-page title for short documents; a cover only when packaging earns its page. Keep headers and footers quiet. Number long reports with PAGE fields; do not add a TOC to a short portfolio automatically. Template-selected layouts outrank these defaults.
