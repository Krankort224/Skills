# Brief

## Inputs

Use the stated purpose/stage, users and activities, site/context, existing design, known areas/budget/schedule, any requested deliverable/format and accepted requirements. Distinguish missing information from contradictory information.

## Procedure

1. Identify the immediate design decision and authoritative project material. Extract fixed requirements, preferences and open decisions without treating examples as project facts.
2. Use [program demand](../references/program-and-space.md#what-activities-and-capacity-must-the-program-accommodate) to turn actual activities and overlap scenarios into room demand, then [area accounting](../references/program-and-space.md#how-can-areas-be-counted-once-and-compared) for the stated measurement boundary. Select [relationships](../references/program-and-space.md#which-relationships-must-the-plan-satisfy) and [movement](../references/program-and-space.md#how-do-people-and-goods-move-through-access-zones) only where they affect the decision.
3. Record site geometry/orientation, access, surrounding context, climate information and existing constraints. Mark provisional assumptions with their consequence and the question that would resolve them.
4. Establish jurisdiction/source applicability through [requirements](../references/requirements.md#select-a-jurisdiction-module) when a normative conclusion matters. Use the matching implemented [module](../references/normative/index.md) to screen actual location, host/embedded use and work/stage conditions. Keep unknown triggers or unsupported jurisdiction coverage explicit; continue independent programming/composition while dependent evidence is unavailable.
5. Check the program's internal consistency: area totals versus footprint/floors, contradictory adjacency, public/service conflicts and incompatible fixed constraints. Do not silently add area or relax a requirement.
6. Ask only the missing questions that materially change the next decision. If useful work can proceed, deliver a bounded provisional brief and state assumptions instead of stopping at a questionnaire.

## Result

Produce an actionable brief containing purpose/stage, activity/space schedule with defined metrics, relationship priorities, fixed constraints, assumptions and open decisions. Use the project's existing format. For an existing design, add only the missing context needed for the requested revision.
