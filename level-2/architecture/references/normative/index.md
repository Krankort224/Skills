# Normative jurisdiction modules

Determine the project's actual jurisdiction through the
[shared requirements procedure](../requirements.md#select-a-jurisdiction-module).
This index lists implemented modules only; it is not a document catalog.

| Jurisdiction | Entry points |
| --- | --- |
| Russian Federation | [Selection procedure](ru/applicability.md), [task-to-record routes](ru/routes.md), [catalog and coverage](ru/index.md) |

Unknown jurisdiction leaves dependent normative conclusions open. A known
jurisdiction absent from this index is a coverage gap; do not use the Russian
module as a fallback. Independent design methods and calculators remain shared.
