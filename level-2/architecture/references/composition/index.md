# Composition: setting, form and expression

Select a consequential architectural choice and compare it against actual use, site and physical performance. A named style, a clean elevation or a compelling diagram does not by itself resolve those constraints.

Open a known method directly. Otherwise choose one question below and follow only the dependencies relevant to the decision; reading every sibling or the source ledger is unnecessary.

| Question | Local method and distinction |
| --- | --- |
| Which site cues and arrival should shape the idea? | [arrival and setting](../context/site/arrival-and-setting.md) — Translate actual setting rather than copying appearances. |
| Which organizing concept fits the brief? | [parti](massing/parti.md) — Compare seven organizational hypotheses and hybrids. |
| How should solids and occupied voids work? | [mass and void](massing/mass-and-void.md) — Compare add, carve, step and split operations on the same basis. |
| Can section generate the form? | [section form](massing/section-form.md) — Keep level, occupied height, light and support consequences. |
| What should hierarchy and rhythm communicate? | [hierarchy and rhythm](facade/hierarchy-and-rhythm.md) — Relate person, building and context scales to actual use. |

| How can desired character become decisions? | [character to decisions](styles/character-to-decisions.md) — Use experiential traits, evidence and alternative means. |
