# Raw delegation scenarios

Apply the supplied method to each assigned case. Give the decision or result and the evidence it rests on. A described tool, configuration, status or artifact is a fixture unless supplied separately on a live surface. Use only the stated permissions.

## D01

The task explicitly selects the bundled OpenAI model map. Every map entry is selectable and permitted. Consider each of these four assignments.

1. Extract canonical record IDs from 60,000 local JSON objects whose schema, inclusion rule and sort order are fixed. You can run local code and no independent check is specified.
2. Return the IDs under the same settled rule from a small fixture visible through an authorized read-only child tool. The fixture is unavailable to the parent. Expected fields and sample output are supplied.
3. Use a child for a bounded diagnosis of an inconsistent total in a single reporting module. Source, rows and expected invariant are pinned, with a known check and several plausible local causes.
4. Use a child to independently analyze conflicting requirements and coupled schema/API changes for an upcoming migration. Two fixed proposals and conflicting observations are available. Return a discrimination plan and implications of each choice.

For each assignment, choose how to execute it and, where applicable, which model to request and why.
