# Hermes Agent delegation

Official Nous Research documentation checked 2026-11-22 (Europe/Moscow). This profile covers the model-facing `delegate_task` tool and session controls in Hermes Agent. Evidence is documentation only, with native behavior untested in this environment. Check the live tool schema, active profile, backend, session type, and permissions before dispatch.

## Dispatch and routing

- Send `goal` and `context` for one child or a `tasks` array for a batch. Each child starts a fresh conversation. A resolved workspace can contribute project instructions. Include the explicit assignment and required-skill list in all cases. The parent receives the child's summary. Check the summary and any reported artifacts. [Dispatch](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#single-task) · [Child context](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#how-subagent-context-works)
- With the built-in `default` backend, `delegation.model` fixes the worker model across tasks. Omit it to inherit the parent's model. The provider or endpoint comes from delegation configuration or the parent. The built-in tool has no per-task model parameter. [Built-in routing](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#model-override)
- With the official `advanced-delegation` plugin enabled on Hermes 0.22.5 or newer, `model_map` can expose named `option` choices and `profile_routes` can expose `profile` choices from configured allowlists. Omitting the selection uses the active backend's configured default or the parent's model if no default is set. An invalid or unresolvable explicit selection fails, as does an unavailable backend. Routed results report the resolved route. A model route uses its own `fallback_providers` when set, including an empty list to disable fallback, or inherits `delegation.fallback_providers`. A profile route uses that profile's fallback chain and can change credentials, skills, and terminal policy. Confirm the route and its effective fallbacks are authorized. [Delegation strategies](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#delegation-strategies-delegationbackend) · [Advanced Delegation](https://hermes-agent.nousresearch.com/marketplace/advanced-delegation)
- Default delegation inherits enabled parent toolsets with child restrictions and starts a separate terminal session in the shared working directory. A child is a `leaf` by default. Descendants require `role="orchestrator"`, `delegation.orchestrator_enabled`, sufficient `delegation.max_spawn_depth`, and assigned spawning rights. Git worktree isolation is opt-in for the local terminal backend. It can create branches automatically and can fall back silently to the shared checkout. Use only authorized workspaces and confirm isolation before parallel writes. [Tool access](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#inherited-tool-access) · [Depth](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#depth-limit-and-nested-orchestration) · [Worktrees](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#worktree-isolation)

## Completion and recovery

- A top-level call returns a handle when the session supports later delivery. Results return between parent turns. An orchestrator child waits for its workers, and a stateless surface can run synchronously. Track the handle and available child IDs. [Batch and delivery](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#batch-mode-details) · [Session lifetime](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#lifetime-and-durability)
- Where exposed, `delegate_task(action="list")` reports the parent's children with live or queued work. Use `steer` to redirect a running child and `stop` to cancel it by ID. `continue` can restore a finished or resumable child's transcript and route when its session and saved state support it. `/stop` or closing/resetting the owning session stops its background children and dependent descendants. Stopping only the current turn leaves background work running. Treat `interrupted` output as partial and verify side effects when a restart leaves the prior attempt `unknown`. [Child controls](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#steering-a-running-subagent) · [Session lifetime](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#lifetime-and-durability)
- With the gateway's opt-in `delegation.auto_resume`, a child stopped by a provider limit can still be queued to resume. `list` reports `waiting_to_resume`, and the child retains its write scope while queued. Starting a replacement leaves the queued resume active. Before assigning overlapping work, wait for a terminal result or cancel the queued resumption with `delegate_task(action="stop", subagent_id=...)` and confirm the child is settled. [Automatic resume](https://hermes-agent.nousresearch.com/docs/user-guide/features/delegation#automatic-resume-delegationauto_resume-opt-in)
