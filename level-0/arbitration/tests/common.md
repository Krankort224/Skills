# Common decision criteria

Use these criteria for the [raw common cases](inputs/common.md), alongside the [Codex dot](codex-dot.md) and [Hermes](hermes.md) cases when their routes are affected. C1–C22 retain the protected decisions of the predecessor suite. Case IDs, raw inputs, criteria and operation routes remain separate from run results.

## Apply the cases

Fix the baseline, candidate revision, selected raw case IDs, criteria, scoped tools and permissions before the run. For a fresh application, supply the pinned method and applicable task constraints, selected raw cases and artifacts, and the requested decision. Withhold these evaluator files, prior verdicts, author reasoning and expected findings from the initial assignment. For repository review, likewise give the non-author the agreed requirements, pinned baseline/candidate and factual observations, keeping author diagnoses out of the initial package. Record the recipient's history exposure and actual input. Use an isolated decision exercise unless a specific native action is separately authorized.

For each case retain the actual response and relevant actions with its exact revision, run surface, criteria, evidence, gaps and outcome. Grade decisions and requested effects against the observable criteria, including any omissions. Preserve deviations. Static source and link inspection, actual fresh agent application, and native effects are distinct observations. Decision exercises alone do not verify delivery, persistence, cancellation, external writes, publication, acceptance or deletion. Credit a native effect only from evidence of the specified action and resulting state in that surface.
