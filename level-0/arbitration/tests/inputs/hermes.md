## C27

Draft the request and state the evidence to look for after sending it.

## C28

One field's compatibility range is unclear. The rest of the customer workbook is private. The peer says they could patch the endpoint using extra paid capacity if asked. Draft the message and identify current responsibility and any decisions still needed.

## C29

An independently addressable minion has a bounded report from the user. Its existing grant permits one internal read-only child to compare two public contract versions. The child's handle can be resumed by the minion, but the user and adjacent specialists have no request route to it. The child has returned a log and part of its check remains queued. Who can use which return route and what should the minion establish before claiming completion?

## C30

The specialist has access and this read task is in its current grant. A main agent is leading an unrelated project rollout. Another bot's old title says “catalog lead,” but the current assignment identifies this export specialist as the owner of the comparison. Decide intake, ownership and return.

## C31

Prepare the next actions and identify what evidence can be delivered.
